# Cycle log

State of the PROCESS, separate from the state of contacts. The date and counters are
written by the script (mechanical → machine), the decision is written by a human as the
`--run "..."` argument (meaning → human). One change per run; "no changes" is an honest
entry — it is visible in history, unlike silence.

```bash
node board.mjs --run "change: dropped X from query Y — it caught self-promo"
```
